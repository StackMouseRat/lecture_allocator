# 个人调度规则（不上课时的活动倾向）

## 时间划分
| 时段 | 定义 |
|---|---|
| 工作日白天 | 周一~五 非上课时段 |
| 工作日晚上 | 周一~五 晚间无课时段 |
| 休息日白天 | 周六/周日 白天 |
| 休息日晚上 | 周六/周日 晚上 |

## 规则（空闲时刻判定优先级）
1. **白天必睡**：太原、萨里（白天空闲 → 一定睡觉）
2. **工作日作业优先**：本周作业需求满足前，工作日空闲一律做作业
   - 作业需求 = ⌈(本周实验课次 + 专业课次)/2⌉ 课时/周
   - "专业课" = 学门核心（高数/线代/普物等）+ 学类核心 + 专业核心 + 专业选修（course_types.json）
3. **爱好时间**：酒匂 → 工作日；萨里/暴风雨/太原 → 周末
4. **默认**：其余空闲 → 待命（按人设）
