太原号驱逐舰

**太原号** 是中国人民解放军海军的 **07型(鞍山级)驱逐舰4号舰**，也是新中国建立后最早的驱逐舰之一。

1955年6月28日，第二批两艘两艘苏制07型驱逐舰抵达青岛，7月6日举行了接收仪式，其中“列考尔特内依”号命名为“太原”舰，舷号304（1961年改为204,1974年至退役为104）。

1970年改装为 **导弹驱逐舰**，1986年为避免与台湾海军重名，改名 **“青岛”**，1991年退役后坐滩于大连老虎滩海洋公园，供大连舰艇学院学员练习并开放游客参观（注：对外参观现已停止）

2026年2月,经相关机构安全评估，认为其舰体存在重大安全隐患，于2月24号开始其舰体拆解工作。好消息，2016年6月，她已转生为052D型第11号舰，舷号131【太原】

  - 排水量：1675 吨（标准）；2150 吨（满载）
  - 长：112.8 米
  - 宽：10.2 米
  - 吃水：4 米
  - 动力：48000 匹
  - 装置：3 x 锅炉；2 x 蒸汽轮机；2 x 推进器
  - 航速：32 节
  - 航程：2,600 海里/20 节
  - 编制：240-290 人
  - 武器： **（苏联7型驱逐舰出厂）** 4 x 单装130mm/50 B-13主炮；2 x 单装76.2mm 34-K防空炮；2 x 单装45mm 21-K防空炮；2 x 12.7mm DshK机枪；2 x 三联装533mm鱼雷发射器；60-95 x 水雷；25 x 深水炸弹。

    **（中国07型驱逐舰最终状态）** 4 x 单装130mm/50 B-13主炮；4 x 61式双联装37mm防空炮；2 x 双联装上游-1导弹发射架。
