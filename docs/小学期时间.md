```
2023-02-20 ──── 第2学期（16周）──── 2023-06-12
                                        │

                                        │

        小学期第2段（开学前2周）   2023-08-21 ~ 2023-09-03
                                        │
2023-09-04 ──── 第3学期（开学）────
```
