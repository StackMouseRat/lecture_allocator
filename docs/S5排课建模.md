## 二、口径决定（统一，消除旧引擎漂移）

1. **实训块口径**：采用 `docs/进展记录.md` 与 `总调度规则`"比例自动调整（4+6→6+5等）"口径 —— **周三下午 W6-11 半天 + 周五全天 W12-16**（24+40=64）。
   - 原 `courses_sem5.json` desc 写 1-4/5-10（从未实现的数据漂移）：W5-10 周五全天被堵时，理论13节+实验2节的周容量恰好打满，CSP 超时（诊断验证）；
   - 6-11/12-16 使全天周落在电机学(1-11)/电力系统基础(1-10)结课之后，理论降至9节/周，容量充裕（求解 34K 节点）。
2. **信号与系统·讨论学时**：修正 `courses_sem5.json` 的 total_hours **16 → 4**（weeks=9-10 × 1次/周 × 2学时 = 4学时；16 是 `build_semesters.EV()` 复制残留）。
3. **大三实验连续周**：`总调度规则`五.4 —— 大一大二隔周、**大三起连续周**。S5 全部实验连续周。
4. **实验时段**：`总调度规则`五.5 —— 下午优先（课时多优先）、下午排不下兜底晚间。S5 实验候选 slot5（下午2小节=4学时）优先，slot7（晚间4小节）兜底。
5. **同课间隔≥2天**（`经验教训`L3 直接距离）：CSP 内置约束。旧引擎 S5 存在"电力系统基础（上）周一→周二隔1天"违规，重排后必须 0 违规。
6. **周二下午（slot5/6）禁一切课**：CSP 内置。
7. **实验周次定稿**（容量平衡，诊断验证）：电力电子实践 W1-5、自控实验 **W4-9（2学时/次×6次）**、电机学实验 W6-8、信号实验 W9-11、微机实践 **W7-10 + W12-15**（W4 仅电力电子实践一门，避开实训+形势政策+多实验重叠的容量死角）。
