# 机电技术创新实训 授课方案

> 总学时 64 ｜ 11天（6 半天×4学时 + 5 全天×8学时）

| 周次 | 节次 | 授课内容 |
|---|---|---|
| 第6周 | 第1节 | 环节一 背景调查 · 全钒液流电池工作原理与系统组成 |
| 第7周 | 第1节 | 环节一 背景调查 · 国内外技术现状与流道设计调研 |
| 第8周 | 第1节 | 环节二 方案设计 · 电池结构与多流道方案设计（蛇形/平行/叉指等） |
| 第9周 | 第1节 | 环节二 方案设计 · 流道工艺路线与测试方案设计 |
| 第10周 | 第1节 | 环节三 流道制作与组件准备 · 多种流道板设计与加工制作（蛇形/平行/叉指等） |
| 第11周 | 第1节 | 环节三 流道制作与组件准备 · 电极/隔膜/电解液组件检验与电堆装配准备 |
| 第12周 | 第1节 | 环节四 电池总装 · 电堆叠装（电极/膜/双极板）与密封紧固 |
| 第13周 | 第1节 | 环节四 电池总装 · 电解液循环管路与储液系统搭建 |
| 第14周 | 第1节 | 环节五 实验验证 · 充放电性能测试（库仑效率/电压效率） |
| 第15周 | 第1节 | 环节五 实验验证 · 多种流道电效率对比实验与数据分析 |
| 第16周 | 第1节 | 环节六 最终汇报 · 实训成果汇报与展示 |
