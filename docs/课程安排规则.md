# 授课方案（syllabus）编制规则 v1.0

> 适用范围：data/syllabus_semN.json + docs/课程进度/semN/*.md 的生成与维护
> 生成器：gen_syllabus_sem1.py / gen_syllabus_sem2.py（按学期）

## 一、课时 → 课次换算（与排课引擎一致）
| 总学时 | 每周课次 | 分布 |
|---|---|---|
| 32 | 1次/周 × 16周 | 全学期 |
| 48 | 1全(16次)+1半(8次) | 如概率论/毛概 |
| 64 | 2次/周 × 16周 | 电路/大英 |
| 96 | 3次/周 × 16周 | 高数 |
| 实验 | 按次学时：32/4=8次、24/3=8次、8/2=4次 | 隔周或连续 |
| 半学期课 | 12周前结课 | half_term |
| 集中实践 | 半天/全天块 | 实训/军训等 |

## 二、授课方案内容规则（硬约束）
1. **禁止凑数类内容**：复习/答疑/机动/模拟考试/考前冲刺/习题课/总结/研讨/考核/测验——一律不得作为正式课次
2. **每节课必须为实质教学内容**，16周逐节排满，不得循环重复（素材数 ≥ 节数）
3. **深化/应用内容跟随对应知识点**：讲完一章立即安排该章深化，禁止"前N章授课+后M节深化"两段式堆放
4. **导师课程**：每节标题为论文题目式（如"电网不对称故障时三相四线制VSG穿越方法研究与装置研制"），参考湖南大学真实论文风格；句式多样避免雷同
5. **实践课收尾**：选修等课程末节为该课程自己的实践环节（读书会/作品讲评/调研报告/情景演练等），禁止统一占位
6. **实验课**：按"绪论/误差理论→实验1..N"编排；上机课（CAD/Python）按软件教学顺序编排

## 三、学时显示规则
- 每次学时（hps）：理论课=2、普物实验=3、4学时实验=4、上机按定义
- 总学时 = 课次数 × hps（非 周次×每周次×2）
- 4学时实验晚间占4小节（slot7/8/9/12）；3学时3小节；2学时2小节

## 四、质量校验（check_syllabus.py）
- 禁词扫描：复习/答疑/机动/模拟/考前/习题课/研讨/总结/考核/考试/测验
- 重复检测：同课内 topic 重复数
- 疑似占位：长度<8且无"·"分割
- 校验命令：`python3 check_syllabus.py 1 2`（可指定学期）
