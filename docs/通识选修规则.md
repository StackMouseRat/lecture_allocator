# 通识选修选课规则

## 规则（已固化）
1. 每人选 **4门通识选修 × 2学分 = 8分**（满足培养方案通识选修8学分）
2. **排除项**（不计入8分）：心理健康、四史、哲学导论
3. **太原**不选写作类（学术论文写作/应用写作等）
4. 按人设主题从学校通识选修目录（380门，`hnu_courses/raw_text.txt`）抽取
5. **固定种子 seed=102 可复现**（生成"第2轮"方案）
